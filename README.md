# Локальный парсер Telegram-каналов

Приложение поднимает локальный веб-интерфейс для парсинга **публичных** Telegram-каналов через веб-версию `t.me/s/<channel>`.

## Возможности

- Фильтрация по ключевому слову.
- Фильтрация по дате `от/до`.
- Фильтрация по минимальному числу просмотров.
- Поле проверки канала (кнопка **"Проверить канал"**).
- Кнопка выгрузки результатов в CSV.

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

После запуска откройте: `http://127.0.0.1:5000`.

## Ограничения

- Работает только с публичными каналами.
- Telegram может ограничивать частые запросы по IP.
- Формат веб-страницы Telegram может меняться, что потребует обновления CSS-селекторов.
