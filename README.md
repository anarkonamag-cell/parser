# Локальный Telegram Channel Finder (без Telethon)

Локальное веб-приложение для поиска Telegram-каналов и выгрузки `@username` в CSV.

## Что изменено

- Убран Telethon и прямое MTProto-подключение.
- Поиск каналов выполняется через веб-источники (поисковые страницы каталогов) + анализ публичной веб-ленты `t.me/s/<channel>`.
- Режимы прокси в интерфейсе оставлены для совместимости UI, но в текущем веб-режиме не используются для MTProto.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Открыть: `http://127.0.0.1:5000`.

## Ограничения

- Подписчики и ER в веб-режиме могут быть недоступны/приблизительны.
- Работает только с публичными каналами.
