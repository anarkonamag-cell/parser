# Локальный Telegram Channel Finder

Локальное веб-приложение для поиска **каналов Telegram** и выгрузки их `@username` в CSV по вашим фильтрам.

## Что делает

- Источник: Telegram API через `Telethon`.
- Ищет каналы по списку запросов.
- Применяет фильтры:
  - комментарии открыты;
  - категория контента;
  - минимум подписчиков (по умолчанию 500);
  - активность (посты за период + последний пост свежий);
  - активная аудитория (ER = avg views / subscribers).
- Выгрузка в CSV.
- Режим работы: по запросу из браузера (нажали кнопку — получили результат).

## Что нужно заранее

1. Создать `api_id` и `api_hash` на https://my.telegram.org.
2. Указать номер телефона Telegram в форме.
3. При первом запуске код подтверждения (и 2FA-пароль при наличии) вводится в консоль, где запущен `python app.py`.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Открыть: `http://127.0.0.1:5000`.

## Важные замечания

- Категория определяется эвристически по названию/описанию канала.
- Метрики активности рассчитываются по последним сообщениям в заданном окне анализа.
